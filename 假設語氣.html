假設語氣

假設語氣用來說「不是真的」的事：如果我是你、早知道就好了、要是當時沒錯過那班車。它的規則很固定，就是把時態「往過去退一格」。學會之後，作文表達後悔、想像、建議都會更有層次。

這一節回答同一個問題的四個面向：「怎麼用英文說一件與事實相反的事？」

PART 1 ・ 與現在事實相反

「如果我有翅膀」為什麼用過去式

情境

比較這兩句：

(1) If it rains tomorrow, we will stay home.

(2) If I had wings, I would fly to school.

觀察

(1) 明天下不下雨不知道，是真的有可能發生的「條件句」，用現在式＋will。(2) 我現在沒有翅膀，是不可能的事，英文就把時態往過去退一格：現在的事用過去式，will 變 would。這個「退一格」就是在告訴讀者：這不是真的。

規律 → 公式
If + S + 過去式（be 動詞一律用 were）, S + would / could / might + 原形 V

If I were you, I would talk to the teacher.
If I had more time, I could join the club.
were 不分人稱。假設語氣裡 be 動詞用 were：If I were、If he were。口語有人說 If I was，但考試和作文請用 were。
PART 2 ・ 與過去事實相反

早知道就好了

情境

「如果我昨天有複習，今天的小考就會及格了。」但事實是：昨天沒複習，小考也沒過。

If I had reviewed yesterday, I would have passed the quiz.

觀察

這次要說的是「過去」的相反，同樣往回退一格：過去式退成過去完成式 had p.p.，主要子句變成 would have p.p.。

規律 → 三種假設對照
類型if 子句主要子句例句
真實條件現在式will + VIf you hurry, you will catch the bus.
與現在相反過去式 / werewould + VIf I lived closer, I would walk to school.
與過去相反had + p.p.would have + p.p.If she had left earlier, she wouldn't have missed the train.
PART 3 ・ 混合假設

過去沒做的事，影響到現在

情境

「如果我當年有學游泳，現在就不會怕水了。」條件在過去，結果在現在。

If I had learned to swim as a child, I wouldn't be afraid of water now.

觀察

兩半各自看自己的時間：if 子句講過去 → had p.p.；主要子句講現在 → would + V。常見訊號是主要子句裡的 now、today。

規律
If + had p.p.（過去的相反）, S + would + 原形 V（現在的結果）+ now
PART 4 ・ wish、as if 與省略 if

不用 if 也能假設

情境

「真希望我現在在海邊。」「他講得好像自己什麼都知道。」這些都是與事實相反，但句子裡沒有 if。

規律 → 四種常見寫法
句型與現在相反與過去相反
S + wish (that)…I wish I were at the beach now.I wish I had studied harder.
If only…If only I knew the answer!If only I hadn't said that!
as if / as thoughHe talks as if he knew everything.She looked as if she had seen a ghost.
Without / But for + NWithout water, we couldn't survive.Without your help, I would have failed.
延伸：省略 if 的倒裝

正式寫作裡可以刪掉 if，把 were、had、should 移到句首。這是綜合測驗和作文都會出現的高分句型：

If I were you, … → Were I you, …
If I had known the truth, … → Had I known the truth, …
If it should rain, … → Should it rain, …
作文用法。寫經驗反省或建議時，一句假設語氣就能讓內容更深：Had I known how much I would enjoy it, I would have joined the club much earlier.
練習

動手試試看

作答後點選答案或按「對答案」，作答紀錄會保留在這台裝置。
Q1選出正確的形式：

If I ______ a million dollars, I would travel around the world.

看解析
B。主要子句是 would + V，與現在事實相反，if 子句用過去式。
Q2選出正確的形式：

If we had checked the weather, we ______ caught in the storm.

看解析
C。if 子句是 had p.p.，與過去事實相反，主要子句用 would have p.p.。
Q3選出正確的形式：

If she had taken the job in Taipei, she ______ there now.

看解析
A。混合假設：條件在過去（had taken），結果在現在（now），用 would + V。
Q4改寫成省略 if 的倒裝句：

If I had known about the party, I would have gone.

看標準答案與解析
Had I known about the party, I would have gone.
Q5中譯英：真希望我昨天沒有熬夜。
看標準答案與解析

I wish I hadn't stayed up late last night.

與過去事實相反，wish 後面用 had p.p.。

本節重點
  • 假設語氣＝時態往過去退一格，用來表示「不是真的」。
  • 與現在相反：If + 過去式（were）, would + V。
  • 與過去相反：If + had p.p., would have p.p.。
  • 混合假設：過去的條件，現在的結果，看 now。
  • Were I…、Had I known… 是省略 if 的倒裝高分句型。
